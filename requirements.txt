# Runtime dependencies, curated and pinned.
#
# This file replaces a 225-line `pip freeze` in which only 27 distributions were
# imported by any tracked file and 131 lines were unreachable even as transitive
# dependencies (slideflow, smac, pytorch-lightning, tensorboard, scikit-image,
# saliency, gdown, fpdf2, uv, typer and their closures). Every line below is
# imported by tracked code or tracked notebooks, or is a documented hidden
# runtime dependency; the version is the one installed in the environment that
# produced every published number.
#
# ---------------------------------------------------------------------------
# THIS FILE IS NOT THE SETUP STEP.
#
#     pip install -e '.[dev]'
#
# is. `pyproject.toml` carries the same pins (`tests/test_dependencies.py`
# asserts the two agree, distribution for distribution) and additionally
# installs the six console scripts and puts `project` / `tools` on `sys.path`,
# which is what makes `import project.survival` work outside the container. This
# file exists because `docker/Dockerfile` installs dependencies before any source
# is copied in, and because `pip install -r requirements.txt` is the instruction
# the old README taught.
# ---------------------------------------------------------------------------
#
# Three corrections the packaging audit found, all deliberate:
#
#   * opencv. `opencv-python==4.7.0.72` AND `opencv-python-headless==4.11.0.86`
#     were both pinned. They install the same `cv2` module, so install order
#     decided which one won; `import cv2` resolves to 4.11.0 headless here, so
#     the non-headless pin was a lie about what ran. Headless is kept — it is
#     what ran, and it drops the host `libGL.so.1` / `libglib` requirement.
#   * pillow. The freeze pinned 12.1.1; 12.3.0 is installed and is what produced
#     every published number. The pin follows reality.
#   * `openpyxl` and `topk` are NOT plain imports and are kept anyway:
#     `openpyxl` is reached only through `pd.read_excel(engine="openpyxl")`
#     (tools/fetch_tcga_labels.py:41,44), and `topk` is imported lazily at
#     project/CLAM/utils/core_utils.py:315 by `--inst_loss svm`, i.e. by the
#     frozen WSI baseline — dropping it fails MID-TRAINING, not at startup.
#
# Python: >=3.10,<3.12. torch 2.0.1 publishes no cp312 wheel.
